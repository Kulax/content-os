# Submission Checklist

## Mandatory

- [ ] Live deployed prototype URL
- [ ] Accessible GitHub repository URL
- [ ] 3-4 minute demo video
- [ ] Pitch deck in required template
- [ ] Brief project description

## Product Proof Points

- [x] Prompt-based creation works
- [x] Content DNA is visible
- [x] Experience Plan is visible
- [x] Real media generation works
- [x] At least one adaptive control is visible (API-level via `/api/adapt`)

## Technical Proof Points

- [x] Gemini is central in reasoning flow
- [x] Veo generates real shot assets
- [x] Cloud Storage stores generated assets
- [ ] Cloud Run deployment is stable
- [x] Error handling paths demonstrated

## Demo Reliability

- [ ] Primary live script tested
- [ ] Demo-mode fallback assets prepared
- [ ] Backup recording prepared

## Security and Hygiene

- [ ] No secrets in repository
- [ ] .env excluded from git
- [ ] Service account privileges minimized

## Repository Quality

- [ ] README with setup and architecture
- [ ] Deployment steps documented
- [ ] Demo instructions documented
- [ ] Known limitations documented
