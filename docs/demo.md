# Demo Plan (3-4 Minutes)

## Goal

Demonstrate that CONTENT OS is an adaptive content experience engine, not a single-output generator.

## Flow

1. Problem (20 sec)
- Same content does not work for every user.

2. Creation (40 sec)
- Submit natural-language request.
- Show returned Content DNA and shot-level Experience Plan.

3. Generation (45 sec)
- Show shot asset generation from Veo.
- Show composed scene output.

4. Final Render (30 sec)
- Render final experience from one or more composed scenes.
- Optionally show narration merge and subtitle export.

5. Transformation (40 sec)
- Regenerate with changed audience and duration.
- Highlight selective regeneration potential.

6. Adaptation moment (40 sec)
- Trigger "make simpler" refinement path.
- Show updated blueprint/experience adjustment.

7. Closing (20 sec)
- "We do not generate more content; we make content experienceable by anyone."

## Reliability Strategy

- Live mode: real generation.
- Demo mode: pre-generated assets for deterministic playback.

## Demo Assets to Prepare

- 1-2 strong prompts with predictable outputs.
- Pre-generated shot and scene URLs as fallback.
- Screen recording backup for network/API delays.
